## 样例明细

### A1 售后-退货退款(含订单号)

- **输入**:`订单 SO20261001 买的运动鞋穿了不到一周就开胶了,我要退货退款`
- **期望 AfterSalesInfo**:`is_after_sales=true, order_id="SO20261001", request_type="退货退款", expected_solution="退货退款"`
- **对话回复要点期望**:
  - 表达歉意/理解,安抚用户
  - 不承诺"一定能退"、不给退款金额或到账时限
  - 不编造物流/退款进度等实时数据
  - 说明会记录诉求并转交人工/引导按流程申请

### A2 售后-仅退款(含订单号)

- **输入**:`订单 DD20260915 下单快一周了还没发货,我不要了,请直接退款给我`
- **期望 AfterSalesInfo**:`is_after_sales=true, order_id="DD20260915", request_type="仅退款", expected_solution="直接退款"`
- **对话回复要点期望**:
  - 不编造"已发货/预计到达时间"等物流状态
  - 不承诺具体退款到账时限或金额
  - 说明会记录诉求并转交人工处理

### A3 售后-换货(含订单号)

- **输入**:`上周买的手机壳,订单号 M20261005,收到就是破的,我想换一个全新的`
- **期望 AfterSalesInfo**:`is_after_sales=true, order_id="M20261005", request_type="换货", expected_solution="换货"`
- **对话回复要点期望**:
  - 表达歉意
  - 不承诺具体换货时效/运费承担
  - 引导补充必要信息或转人工

### A4 售后-催发货/物流查询(含订单号)

- **输入**:`订单 SO20261010 都三天了怎么还没发货,帮我催一下`
- **期望 AfterSalesInfo**:`is_after_sales=true, order_id="SO20261010", request_type="物流查询", expected_solution="尽快发货"`
- **对话回复要点期望**:
  - **关键**:不编造物流状态/预计发货时间(本章查不到实时数据)
  - 如实说明暂时查不到物流,不瞎猜
  - 说明会记录并转交人工催单

### A5 售后-投诉(含订单号)

- **输入**:`订单 SO20261020 收到的衣服有很重的异味,联系客服态度还差,我要投诉`
- **期望 AfterSalesInfo**:`is_after_sales=true, order_id="SO20261020", request_type="投诉", expected_solution="投诉处理"`
- **对话回复要点期望**:
  - 表达歉意与重视
  - 不编造处理结果、不承诺赔偿金额
  - 说明会记录并转交人工/投诉渠道

### B1 非售后-闲聊

- **输入**:`你好呀,今天心情不错,你呢?`
- **期望 AfterSalesInfo**:`is_after_sales=false, order_id=null, request_type=null, expected_solution=null`(不触发结构化)
- **对话回复要点期望**:
  - 友好寒暄回应
  - 不触发售后结构化提取
  - 简体中文、简洁口语化

### B2 非售后-售前咨询

- **输入**:`你们店那件加厚羽绒服有 XL 码吗?现在多少钱?`
- **期望 AfterSalesInfo**:`is_after_sales=false`(售前咨询,非售后;其余 null)
- **对话回复要点期望**:
  - 不编造商品库存/价格(本章查不到商品数据)
  - 如实说明并建议咨询/转人工
  - 不触发售后结构化

### C1 边界-信息不全的售后

- **输入**:`我买的东西坏了,想退货`
- **期望 AfterSalesInfo**:`is_after_sales=true, order_id=null, request_type="退货退款", expected_solution="退货退款"`
- **对话回复要点期望**:
  - 引导用户补充订单号/问题描述
  - 不编造订单信息
  - 不承诺退款

### Prompt 迭代说明

轮1 → 轮2 对 `app/prompts.py` 的 `SYSTEM_TEMPLATE` 做了 3 处**通用**修改(未针对单个样例特化):

1. **约束 2**:由"你可以说明会帮忙记录并转交人工处理"(可选)改为"遇到这类诉求,主动说明你会帮忙记录并转交人工客服处理"(主动),修复 A4 人工转交表述偏弱的问题。
2. **约束 3**:补充"一次最多追问 2 个关键问题,用户已经说过的信息不要重复追问",修复 A1/A3 中重复追问用户刚提供信息、追问过多的问题。
3. **结尾**:补充"尽量控制在 3 段以内",抑制回复啰嗦。

轮2 复跑全部 8 组:全部通过,A1/A3/A4 的上述瑕疵消除,其余组无回归。
