# ch03 对话挖掘 Prompt 样例集

> 目的:用 6 组人工构造的客服会话校准「对话挖知识」抽取口径。
> 评估脚本 `scripts/eval_mining.py` 读取本文件中的 `conversation` 代码块,
> 调用真实 DeepSeek 抽取器,逐组打印实际抽取结果与下方「期望问答」的对比。
> 本评估只调用 LLM,不调用 embedding / Milvus。
>
> 口径:只有「可复用于其他用户的政策、流程、商品/尺码知识」才应抽取;
> 订单号、物流单号、地址等一次性信息,纯寒暄,以及客服没有给出有效答案的
> 会话都不应抽取。E 组为应抽取正例,N 组为不应抽取负例。

## 应抽取组

### E1. 售后:质量问题换货

- **预期**:应抽取 1 对问答
- **期望问答**:
  - 问:鞋子开胶了可以换货吗?
  - 答:签收后 15 天内出现开胶等质量问题可以申请换货,审核通过后寄回,仓库验收合格后 48 小时内发出新鞋。

```conversation
user: 你好,我买的鞋子开胶了,能换吗?
assistant: 可以的。自签收之日起 15 天内出现开胶、断底等质量问题,可在「我的订单」里申请售后并选择换货,审核通过后按提示寄回,仓库验收合格后 48 小时内为您发出新鞋。
user: 需要我自己出运费吗?
assistant: 质量问题导致的换货,寄回和重新发货的运费都由我们承担,请勿使用到付。
```

### E2. 运费:包邮门槛

- **预期**:应抽取 1 对问答
- **期望问答**:
  - 问:运费怎么算?满多少包邮?
  - 答:单笔订单实付满 99 元包邮,未满 99 元收取 10 元运费;新疆、西藏等偏远地区运费以下单页展示为准。

```conversation
user: 你们家运费怎么算?满多少包邮?
assistant: 单笔订单实付满 99 元包邮;未满 99 元收取 10 元运费。新疆、西藏等偏远地区的运费以下单页展示为准。
```

### E3. 尺码:卫衣选码

- **预期**:应抽取 1 对问答
- **期望问答**:
  - 问:身高 170cm、体重 60kg 穿卫衣选什么尺码?
  - 答:建议选 M 码;卫衣是宽松版型,喜欢更宽松可以选 L 码,也可以参考详情页的尺码表。

```conversation
user: 我身高 170,体重 60kg,你们家卫衣选什么码?
assistant: 建议选 M 码。这款卫衣是宽松版型,身高 170cm、体重 60kg 左右穿 M 码合身;如果喜欢更宽松的效果可以选 L 码。也可以再参考一下详情页的尺码表。
```

## 不应抽取组

### N1. 纯寒暄

- **预期**:不应抽取问答
- **期望问答**:无

```conversation
user: 你好,在吗?
assistant: 您好,我是小喵,在的,请问有什么可以帮您?
user: 没事,就是打个招呼
assistant: 好的~有需要随时找我。
```

### N2. 订单查询:一次性信息

- **预期**:不应抽取问答
- **期望问答**:无

```conversation
user: 帮我查下订单 202610190001 到哪了?
assistant: 您的订单 202610190001 已于 10 月 18 日发出,快递单号 SF1234567890,当前到达上海转运中心,预计明天送达。
user: 好的,谢谢
assistant: 不客气~
```

### N3. 无答案:客服未能确认

- **预期**:不应抽取问答
- **期望问答**:无

```conversation
user: 你们支持花呗分期吗?
assistant: 这个问题我需要帮您确认一下,请稍等。
user: 好的
assistant: 不好意思,暂时无法确认,建议您联系人工客服咨询。
```
